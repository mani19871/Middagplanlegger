# Utkast til henvendelser (ikke sendt)

Alle filene her er **utkast** og er ikke sendt til noen. `[AVSENDER]` byttes av brukeren (navn, rolle, kontaktinformasjon). Ingen personopplysninger eller interne detaljer skal føres inn før sending. Se også `../tjek-avtale.md` og `../kundeavis-rettigheter.md`.
