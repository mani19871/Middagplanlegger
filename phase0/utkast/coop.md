# Utkast: henvendelse til Coop (ikke sendt)

**Til:** [Coop, kontakt for samarbeid/data]
**Fra:** [AVSENDER]
**Emne:** Forespørsel om priser og tilbud per utsalg til en forbrukerapp for middagsplanlegging

Hei,

Vi utvikler en forbrukerapp som hjelper familier å planlegge ukens middager og regner ut en anslått handlekurv. For å vise ærlige anslag trenger vi pålitelige priser og tilbud fra Coop-formatene (Extra, Prix, Mega, Obs, Marked). Vi vil forstå hva dere kan tilby, og på hvilke vilkår.

1. **Omfang:** Hvilke formater og data omfattes (ordinærpriser, tilbud, katalog, pakningsstørrelser, EAN)? Er det forskjell mellom formatene?
2. **Per utsalg:** Finnes priser og tilbud per butikk eller prissone/kampanjeområde (også for samvirkelag), eller bare nasjonalt? Hvordan identifiseres utsalg?
3. **Tilbudsvilkår:** Hvordan beskrives kampanjer maskinlesbart (mengdekjøp, medlemspris/medlemsfordeler, maksantall, gyldighet)?
4. **Oppdatering:** Hvor ofte oppdateres dataene, og når er nye priser/aviser tilgjengelige?
5. **Format og levering:** API, filer eller annet? Autentisering, rate limit, test-/sandbox-tilgang?
6. **Lisens:** Hva kan vi gjøre med dataene (vise i app, lagre, historikk, vise bilder og logo, vise hele aviser eller bare enkelttilbud)? Krav til kreditering?
7. **Vilkår:** Varighet, oppsigelse, eksklusivitet, ansvar, og hva som skjer med lagrede data ved opphør.
8. **Pris:** Koster tilgangen noe, og hvordan faktureres den?
9. **Alternativ:** Hvis dere ikke deler data direkte, hvilken partner eller tjeneste (for eksempel for tilbudsaviser) bør vi bruke, og på hvilke vilkår?

Vi samler ingen persondata fra dere, og vi viser priser som «anslått» med kilde og dato, aldri som garantert sluttpris.
