# Utkast: oppfølging til Tjek (ikke sendt)

**Til:** [Tjek, kontakt for partnerskap/API]
**Fra:** [AVSENDER]
**Emne:** Skriftlig bekreftelse og vilkår for bruk av tilbudsdata i en norsk forbrukerapp

Hei,

Takk for tilbakemeldingen så langt. [Tilpass: henvis til tidligere kontakt og hva som er sagt eller sendt.] Vi trenger **skriftlig** dokumentasjon av hva vi kan gjøre, siden vi ikke kan bygge videre på muntlige avtaler. Vi ber om svar på følgende:

1. **Omfang:** Dekker avtalen bare tilbudsdata i live-visning, eller også kataloger/aviser? Hvilke land og hvilke kjeder/formater i Norge (Rema 1000, Kiwi, Coop-formater, Meny, Spar, Joker, Bunnpris, Europris m.fl.)?
2. **Rettighetskjeden:** Har dere rett til å lisensiere kjedenes tilbud, aviser og bilder videre til oss, eller må vi avtale med kjedene direkte?
3. **Per utsalg:** Hvilke tilbud gjelder alle butikker, og hvilke er begrenset til områder eller utsalg? Hvordan er det modellert i API-et?
4. **Lagring:** Kan vi lagre tilbud (cache, historikk), og hvor lenge? Vår foreløpige løsning lagrer ingenting og viser bare live-data.
5. **Avissider og bilder:** Kan vi vise avissider og tilbudsbilder, eller bare tekst og pris? Hvilke krav gjelder for logo og bilder?
6. **Kreditering:** Hvilke krav til kildeangivelse og lenking?
7. **Teknisk:** API-nøkkel og autentisering, rate limit og kvote, SLA, endringsvarsel ved API-endringer. (API-et svarer i dag uten nøkkel; vi vil bruke det slik dere ønsker.)
8. **Pris og fakturering:** Kostnad, prøveperiode, prisendring.
9. **Varighet og oppsigelse:** Avtaleperiode, fornyelse, oppsigelse, og hva som skjer med data ved opphør.
10. **Vilkår:** Kan vi få tilsendt gjeldende utviklervilkår/lisensvilkår, og bekreftelse på hvilke av dem som gjelder oss?

Vi samler ingen persondata fra dere. Vi viser tilbud med kilde og gyldighetsperiode.
