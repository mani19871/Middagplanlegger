# Utkast: henvendelse til Rema 1000 (ikke sendt)

**Til:** [Rema 1000, kontakt for samarbeid/data]
**Fra:** [AVSENDER]
**Emne:** Forespørsel om priser og tilbud per utsalg til en forbrukerapp for middagsplanlegging

Hei,

Vi utvikler en forbrukerapp som hjelper familier å planlegge ukens middager og regner ut en anslått handlekurv. For å vise ærlige anslag trenger vi pålitelige priser og tilbud fra Rema 1000. Vi vil gjerne forstå hva dere kan tilby, og på hvilke vilkår.

1. **Omfang:** Hvilke data kan dere dele (ordinærpriser, tilbud, produktkatalog, pakningsstørrelser, EAN)? Gjelder det hele sortimentet, eller et utvalg?
2. **Per utsalg:** Finnes priser og tilbud per butikk eller prissone/kampanjeområde, eller bare nasjonalt? Hvordan identifiserer dere utsalg?
3. **Tilbudsvilkår:** Hvordan beskrives kampanjer maskinlesbart (mengdekjøp, medlemspris, maksantall, gyldighetsperiode)?
4. **Oppdatering:** Hvor ofte oppdateres dataene, og er det en frist for når nye priser/aviser er tilgjengelige?
5. **Format og levering:** API, filer eller annet? Autentisering, rate limit, test-/sandbox-tilgang?
6. **Lisens:** Hva kan vi gjøre med dataene (vise i app, lagre, historikk, vise bilder og logo, vise hele aviser eller bare enkelttilbud)? Må vi kreditere Rema 1000?
7. **Vilkår:** Varighet, oppsigelse, eksklusivitet, ansvar, og hva som skjer med lagrede data ved opphør.
8. **Pris:** Koster tilgangen noe, og hvordan faktureres den?
9. **Alternativ:** Hvis dere ikke deler data direkte, finnes det en foretrukket partner eller tjeneste (for eksempel for tilbudsaviser) vi bør bruke, og på hvilke vilkår?

Vi samler ingen persondata fra dere, og vi viser priser som «anslått» med kilde og dato, aldri som garantert sluttpris.
